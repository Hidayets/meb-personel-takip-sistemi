# MEB Personel Takip Sistemi

Okul personeli için kapsamlı takip ve yönetim uygulaması.

## Özellikler

- **Personel Yönetimi**: Tüm personel bilgilerini tek yerden yönetin
- **İzin Takibi**: Yıllık, hastalık ve diğer izin türlerini takip edin
- **Maaş ve Ek Ders**: Maaş ve ek ders ödemelerini kaydedin
- **Organizasyon Şeması**: Okul organizasyon yapısını görselleştirin
- **Öğrenci İstatistikleri**: Kademe bazlı öğrenci dağılımını takip edin
- **Resmi Belgeler**: Terfi formları ve resmi belgeleri oluşturun
- **Otomatik Güncelleme**: GitHub üzerinden otomatik güncelleme desteği

## Kurulum

### Geliştirme Ortamı

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

### Paketleme (Windows)

```bash
npm run build
```

Oluşturulan kurulum dosyası `release` klasöründe bulunur.

## Teknolojiler

- Electron
